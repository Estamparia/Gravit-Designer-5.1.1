## 🛠️ Example Profile Configuration

Tweak your Gravit experience via a `config.json` file in the user directory. Here's a sample:

```json
{
  "theme": "dark",
  "language": "en-US",
  "grid": {
    "snap": true,
    "spacing": 10
  },
  "ai_integration": {
    "openai_api_key": "sk-...",
    "claude_api_key": "sk-ant...",
    "auto_suggest": true
  },
  "export_defaults": {
    "format": "svg",
    "dpi": 300
  },
  "shortcuts": {
    "duplicate": "ctrl+d",
    "group": "ctrl+g"
  }
}
```

**Why this matters:** Profiles let you switch between workstation and tablet setups seamlessly—no resetting preferences each time.

## 💻 Example Console Invocation

For power users who love the terminal, Gravit Designer 5.1.1 supports headless export via CLI. Install the `gravit-cli` package, then run:

```bash
# Export a .gvdesign file to SVG
gravit-cli export my_design.gvdesign --format svg --output ./exports/

# Batch process all designs in a folder
gravit-cli batch ./projects/ --format pdf --dpi 600

# Check version (2026 build)
gravit-cli --version
# Output: Gravit Designer CLI 5.1.1 (Build 2026.3)
```
